F9 — Tab transitions (fade)

Before

/* layout.css */
.tab-content.active { display: block; }

No transition — tabs snap instantly.

After

/* layout.css */
.tab-content.active { display: block; animation: tabFadeIn 0.2s cubic-bezier(0.2, 0, 0, 1); }
@keyframes tabFadeIn { from { opacity: 0; } to { opacity: 1; } }

Fade animation: 0.2s cubic-bezier(0.2, 0, 0, 1). Doesn't change layout flow — just adds a visual fade-in when tab becomes active.

Material Design 3 alignment

M3 motion spec recomienda cubic-bezier(0.2, 0, 0, 1) para entering transitions (standard easing). 200ms es la duración "short" para micro-interacciones.
